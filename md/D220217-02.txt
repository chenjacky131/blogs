Spider-flow爬虫平台使用教程
----------

by jack at 2022/02/17

##### 1. 准备环境
````
JDK >= 1.8
Mysql >= 5.7 (参考：安装MySQL压缩包，这篇)
Maven >= 3.0 下载地址：(http://maven.apache.org/download.cgi)
````
##### 2. 运行项目
````
1. 前往码云下载页面(https://gitee.com/ssssssss-team/spider-flow)下载解压到工作目录
2. 设置Eclipse仓库，菜单Window->Preferences->Maven->User Settings->User Settings 后边的Browse,然后导入自己的Maven目录的conf目录下的settings.xml文件，然后点Apply,在点OK
3. 导入到Eclipse,菜单file->Import,然后选择Maven->Existing Maven Projects,点击Next>按钮，选择工作目录，然后点击Finish按钮，即可导入成功
4. 导入项目里的数据库,基础表：spider-flow/db/spiderflow.sql
5. 编辑spider-flow-master/spider-flow-web/pom.xml,添加以下依赖
		<!-- 数据库相关 -->                
		<dependency>
		        <groupId>com.baomidou</groupId>
		        <artifactId>mybatis-plus-boot-starter</artifactId>
		        <version>${mybatis.plus.version}</version>
		</dependency>
	    <dependency>
	            <groupId>mysql</groupId>
	            <artifactId>mysql-connector-java</artifactId>
	            <version>8.0.28</version><!--$NO-MVN-MAN-VER$-->
	            <scope>runtime</scope>
	    </dependency>
6. Maven部署,在项目更目录执行下面的命令：
  mvn clean package
7. 打包完成后，在spider-flow-master/spider-flow-web/target/路径下会有一个spider-flow.jar，进入该目录，输入命令执行JAR包
  java -jar spider-flow.jar
8. 当看到以下日志信息即表示JAR包执行成功
Tomcat started on port(s): 8088 (http) with context path ''  
Started SpiderApplication in 8.278 seconds (JVM running for 9.067)  
9. 最后浏览器访问：http://localhost:8088/ 即可使用平台
````
