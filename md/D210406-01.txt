Git常用命令
----------

by jack at 2021/04/06

##### 1. git切换原

````
git remote set-url origin git://****.git
````

##### 2.git拉取代码

````
git pull origin [branchName]
````

##### 3.git恢复staged的修改

````
git checkout [fileath]

````

##### 4.git新建分支

````
git checkout -b [branchName]
````

##### 5.git从另一个分支合并内容

````
git merge [branchName]
````

##### 6.查看当前分支所有

````
git branch -a
````

##### 7.切换分支

````
git checkout [branchName]
````

##### 8.删除本地分支

````
git branch -D [branchName]
````

##### 9.从远程分支拉去代码到本地分支

````
git checkout -b [localBranchNam]e origin/[remoteBranchName]
````

##### 10.同步远程的分支到本地

````
git remote prune origin
````

##### 11.查看本地分支分支对应的远端分支

````
git remote -vv
````

##### 12.删除远程分支

````
git push --delete origin [remoteBranchName]
````

##### 13.撤销到某次提交

````
git reset --hard HEAD^(对应的版本号,不写版本号直接恢复到最近的一个提交)
git push origin HEAD --force // 强制推送到远端,确保远端的东西可以直接覆盖
````
##### 14.提交当前分支到远程并设置它的upstream

````
git push -u origin [remoteBranchName]
````

##### 15.查看哪些分支已经合并入当前分支

````
git branch --merged
````

##### 16.合并某个分支的单次提交

````
git cherry-pick [log_commit(要合并的分支那次提交的log_commit码)]
````

##### 17. 强制合并某个分支的内容到当前分支

````
git reset --hard [branchName(要合并过来的分支)]
git push origin [branchName(当前的分支)] --force

````

##### 18. 分支重命名
````
1.先重命名本地分支
git branch -m 旧分支名称  新分支名称
2.删除远程分支
git push --delete origin 旧分支名称
3.上传新修改名称的本地分支
git push origin 新分支名称
4.修改后的本地分支关联远程分支
git branch --set-upstream-to origin/新分支名称

````
##### 19. 恢复删除的分支
````
git reflog 查看最近30天的本地修改记录
找到要恢复分支最新的一条提交，复制那条提交的hash
git checkout -b <分支名> <commit ID>
````
##### 20. 添加远程仓库地址
````
git remote add <origin(映射的仓库名称)><仓库地址>
````
##### 21. 删除远程仓库地址
````
git remote remove <origin(创建的名字)>
````
##### 22. 标签相关
````
在github上，标签（tags）通常用于给代码库打上语义化的版本号。版本号可以让用户更好地理解和使用代码库的不同版本，而标签则是这些版本号的代表。除了版本号，标签也可以作为一种分类方式，在多个项目中共享相同的标签，方便搜索和浏览相关主题的代码库。
git push --delete origin tagname  //  删除远程标签
git tag -d tagname  //  删除本地标签
````
##### 23. 查看关联的远程分支
````
git branch -vv
````
##### 24. 导出git提交记录
````
git log > commits.txt
````

##### 25. 丢弃本地的修改
````
git reset --hard
````
