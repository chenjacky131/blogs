##### 一、HTML
  1. 如何理解HTML语义化

    . 增强代码可读性

    . 有利于SEO，爬虫依赖标签来确定上下文和各个关键字的权重

    . 在没有样式的情况下，也能很好的呈现内容结构和代码结构
  2. script标签中defer和async的区别

    . script:脚本会阻碍HTML解析，只有脚本下载并执行完才会继续解析HTML

    . async script:解析过程中进行异步脚本下载，下载完立即执行，有可能会阻断HTML解析

    . defer script:完全不会阻碍HTML解析，解析完之后，再按顺序执行脚本
  3. 从浏览器地址栏输入URL到请求返回，发生了什么

    . 输入URL之后解析出协议、主机、端口、路径等信息，并构造一个HTTP请求

    . DNS域名解析

    . TCP的三次握手确定连接

    . 发起HTTP请求

    . 服务器处理并返回HTTP报文

    . 浏览器渲染页面(构建HTML渲染数，构建CSS渲染树，把CSS渲染树附加的HTML渲染树上，形成新的渲染树，展示页面)

    . 端开TCP连接

##### 二、CSS
  1. CSS盒模型介绍
  
    . 有两种CSS盒模型，标准盒模型和IE(替代)盒模型。两种盒模型都是由contnet+padding+border+margin构成。其大小都是由content
+padding+border决定的，但是盒子的宽高，根据盒模型的不同结果数值也不同。标准盒模型只包含content,IE(替代)盒模型包括content+padding+border。可以通过box-sizing来改变盒模型，content-box为标准盒模型，border-box为IE(替代)盒模型。

  2.  CSS选择器和优先级

    优先级是由ABCD的值来决定的，其计算规则如下：

    . 如果存在内联样式A=1,否则A=0;

    . B的值等于ID选择器出现的次数;

    . C的值为类选择器和属性选择器和伪类选择器出现的总次数;

    . D的值为标签选择器和伪元素选择器出现的总次数;

  3. 重排和重绘的理解

    . 重排：无论通过什么方式改变了元素的几何信息(元素在视口中的位置和尺寸带下)，浏览器需要重新计算元素的几何信息，这个
过程叫重排。

    . 重绘：通过构造渲染树和重排阶段，我们知道了哪些元素是可见的，以及元素的样式和几何信息。接下来就可以知道元素在屏幕
中的实际像素，这个阶段叫重绘。

    如何减少重排重绘：

    . 最小化的重排重绘，集中样式改变。

    . 批量操作DOM。通过document.createDocumentFragemnt()来添加要被添加的节点，处理完之后再插入到实际的DOM中。

    . 通过absolute对定位和fixed定位使元素脱离文档流，这在制作复杂动画时，对性能的影响比较明显。

    . 开启GPU加速，通过css属性transform或will-change，使元素在独立的层中渲染。

  4. 对BFC(Block Formatting Context块级格式化上下文)的理解

    元素的布局会受到尺寸，定位，子元素，兄弟元素和视口尺寸的影响。是css渲染的一部分，用于决定块级元素布局及浮动相互影响范围的一个区域。

    BFC的一些特性：

      . 块级元素会在垂直方向一个接一个的排列，和文档流的排列方式一致。

      . 在BFC中，上下相邻的两个元素的margin会重叠，创建新的BFC可以避免外边距重叠

      . 计算BFC的高度时，需要计算浮动元素的高度。

      . BFC区域不会与浮动的元素发生重叠。

      . BFC是独立的容器，容器内部元素不会影响容器外部的元素。

      . 每个元素的左外边距和容器的左边框相接触。

    创建BFC的方式：

      . absolute定位或fixed定位

      . 行内块元素，即display为inline-block的元素

      .overflow的值不为visible
  5. 两栏布局(左侧宽度固定，右侧内容自适应)

    . 左侧元素浮动，宽度固定。右侧设置左边距为左侧元素宽度的数值。

    . 左侧元素浮动，宽度固定。右侧设置overflow：hidden，从而创建BFC区域

    . 利用flex布局，父元素display:flex;左元素宽度固定，右元素flex: 1;

    . 利用绝对定位，左侧元素绝对定位，设置固定宽度。右侧设置左边距为左侧元素的宽度。

    . 利用绝对定位，右侧绝对定位left设置为左侧元素宽度，其余方向为0。左侧设置固定宽度。

  6. 实现圣杯布局和双飞翼布局

    . 使用float布局。

    . 两侧使用负值以便和中间内容横向折叠。

    . 防止两侧内容被中间覆盖，圣杯用padding，双飞翼用margin。

  7. 水平垂直居中

    . 子元素设置left:50%,top:50%，将现有元素左上角移到中心点，然后通过transform: translate(-50%,-50%)将元素中心点移到父元素中心点。此方法可以不设置宽高。

    . 将子元素上下左右设置为0，margin设置为auto。此方法宽高必须固定。

    . 将子元素left,top设置为50%把子元素左上角移到父元素中心点，再通过margin-top,margin-left设置50%将子元素中心点移到父元素中心点。

    . 父元素设置display：flex,justify-content:center,align-items: center;

  8. 行高，父元素行高如果写了百分比，子元素的行高继承的是父元素的font-size*百分比算出来的值。

###### 三、Javascript

  a. 数据类型

    . JavaScript的基本数据类型包括Undefined，Null，Boolean，String，Number，Object，Symbol，BigInt，其中Symbol和BigInt为ES6新增的数据类型。Symbol代表独一无二的值，最大的用法是用来定义对象的唯一属性名。BigInt可代表任意大小的整数。

    . 值类型和引用类型，值类型存在栈中，引用类型存在堆中。

    . typeof能判断所有值类型和函数，不可对Null、对象、数组进行精确的判断，应为都返回'object'。

    . instanceof能判断对象类型

    . Object.prototype.toString.call()，所有原始数据类型都能判断。

    . 判断数组的方法，Array.isArray(arr),arr.__proto__ === Array.prototype,arr instanceof Array,Object.prototype.toString.call(arr) === '[object Array]';

    . 深拷贝

````
/**
 * @description: 对象的深拷贝
 * @param {*} obj 要拷贝的对象
 * @param {*} map  用于存储对象循环引用的地址
 * @return {*}
 */
function deep(obj = {}, map = new Map()){
  if(typeof obj !== 'object'){  //  基本数据类型
    return obj;
  }
  if(map.get(obj)){ //  循环引用的对象
    return map.get(obj);
  }
  if(Object.prototype.toString.call(obj).slice(8, -1) === 'Date'){ //  Date特殊对象
    return new Date(obj);
  }
  if(Object.prototype.toString.call(obj).slice(8, -1) === 'RegExp'){ //  RegExp特殊对象
    return new RegExp(obj);
  }
  let result = {}
  //  初始化放回结果
  if(obj instanceof Array ||
  //  加||是为了防止Array的prototype被重写， Array.isArray也是如此。
  Object.prototype.toString(obj) === '[object Array]'){
    result = []
  }
  //  防止循环引用
  map.set(obj, result);
  for(let key in obj){
    //  保证key不是原型属性
    if(obj.hasOwnProperty(key)){
      //  递归调用
      result[key] = deep(obj[key], map);
    }
  }
  return result;
}
````

  b. 闭包: 每当创建一个函数，闭包就会在函数创建的同时被创建出来。可以在一个内层函数中，访问到外层函数的作用域。闭包的应用：

````
// 函数作为参数被传递
function print(fn){
  const a = 200;
  fn();
}
const a = 100;
function fn(){
  console.log(a)
}
print(fn);  // 100

// 函数作为返回值被返回
function create(){
  const a = 100;
  return function(){
    console.log(a)
  }
}
const fn = create();
fn();// 100

````

  闭包自由变量的查找是在函数定义的地方向上级作用域查找。而不是在函数执行的地方。

##### 五、HTTP

  . 强缓存：Cache-Control，有max-age:缓存最大过期时间，秒。no-cache:可以在客户端存储资源，每次都必须去服务器做新鲜度校验，来决定是否从服务器获取资源(200)还是从客户端获取资源(304)。no-store:永远都从服务器获取资源。

  . 协商缓存: 资源标识，在response-header中，有两种，Last-Modified:资源的最后修改时间，请求时会通过if-Modified-Since进行对比。Etag:资源的唯一标识，一个字符串，相当于指纹,请求时会通过if-None-Match进行对比。

  . 优先使用Etag，Last-Modified只能精确到秒级，如果资源被重复生成，而内容不变，则Etag更精确。

  . 三种操作对HTTP缓存的影响：正常点击连接和前进后退，强缓存和协商缓存都有效。f5刷新页面，强缓存失效，协商缓存有效。ctrl+f5强制刷新，强缓存和协商缓存都失效。

  . HTTP2有哪些改进:头部压缩、多路复用、服务器推送。

##### 八、常见手写

  1. 防抖
````
  /**
   * @description: 防抖函数(带立即执行和取消功能)
   * @param {*} func  需要包装防抖的函数
   * @param {*} wait  等待时间
   * @param {*} immediate 是否立即执行
   * @return {*} result 返回值
   */  
  function debounce(func, wait, immediate){
    let timer, result;
    let debounced = function(){
      let context = this; //  绑定this
      let args = arguments; //  获取参数
      if(timer) clearTimeout(timer);
      if(immediate){
        //  如果已经执行过了，timer有值，则不再执行
        let callNow = !timer;
        timer = setTimeout(() => {
          timer = null;
        }, wait);
        if(callNow) result = func.apply(context, args);
      }else{
        timer = setTimeout(function(){
          func.apply(context, args);
        }, wait);        
      }
      return result;
    }
    debounced.cancel = function(){
      clearTimeout(timer);
      timer = null;
    }
    return debounced;
  }
````
  2. 节流
````

  /**
   * @description: 节流函数
   * @param {*} func  需要包装节流的函数
   * @param {*} wait  等待时间
   * @param {*} options 只有三种情况{leading:false}不立即执行或{trailing:false}最后一次不执行或{}都执行
   * @return {*}
   */  
  function throttle(func, wait, options){
    let timeout,context,args,result;
    let previous = 0;
    if(!options) options = {};
    let later = function(){
      previous = options.leading === false ? 0 : +new Date();
      timeout = null;
      func.apply(context, args);
      if(!timeout) context = args = null;
    };
    let throttled = function(){
      let now = +new Date();
      if(!previous && options.leading === false) previous = now;
      let remaining = wait - (now - previous);      
      context = this;
      args = arguments;
      if(remaining <= 0 || remaining > wait) {
        if(timeout){
          clearTimeout(timeout);
          timeout = null;
        }
        previous = now;
        func.apply(context, args);
        if(!timeout) context = args = null;
      }else if(!timeout && options.trailing !== false){
        timeout = setTimeout(later, remaining);
      }
    }
    throttled.cancel = function(){
      clearTimeout(timeout);
      timeout = null;
      previous = 0;
    }
    return throttled;
  }
````
